# Nomad Unity Bridge

Live, one-way scene preview from Nomad Sculpt to the Unity Editor.

[**View on GitHub →**](https://github.com/kanzaki1201/nomad-unity-bridge)

<video controls playsinline preload="metadata" src="./assets/nomad-unity-bridge.mp4" aria-label="Nomad Sculpt to Unity live scene sync demo" style="width:100%;height:auto"></video>

- **Live scene sync:** Preview multiple Nomad objects in Unity.
- **Unity materials:** Assign a material to each synced object for preview.
- **Object updates:** Receive mesh, transform, visibility, and name changes.
